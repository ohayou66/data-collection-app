# UMI 操作与标定

[文档目录](../README.md) · [项目首页](../../README.md)

以下是当前源码的操作说明；使用端需要安装相应版本才能获得这些功能。

## 采集流程

1. 选择双臂或单臂模式和任务，检测相机、编码器、Galaxis VR 与 PICO。
2. 选择相机角色，将所选夹爪闭合并确认最小值；参数变更后重新确认。
3. 启动采集服务，等待设备与监控就绪，再开始一轮录制。
4. 等待页面进入录制状态；完成一轮后查看后台保存状态，失败时保留数据并显示原因。

启动前会检查本机监控端口。端口占用时在停止预览或接管设备之前报错。旧 XR 服务按 App 自有可执行文件的精确路径识别，包括旧安装版本；不按进程名字批量结束其它程序。

## 标定、角度与相机亮度

UMI 传感器读数、闭合最小值和监视曲线统一以度数（°）显示。设备确认阶段读取传感器
原始角度；将夹爪闭合后确认最小值，采集监视与保存使用以该位置为 0° 的相对角度，
左右夹爪打开均沿正方向增加。标定后因误差出现的负相对角度统一发布、显示并保存为 0，
监视接口保留与记录相同的数值精度，仅在界面转为度数后显示两位小数。
启动采集时夹爪已经张开，也保留相对于标定位置的角度，
不会把每段首帧重新当作零点。串口、标定参数和 rosbag 内的 JointState 沿用原采集代码
的弧度单位（例如 30° 保存为 π/6 rad），保存值已扣除闭合零点，不是上电绝对角度。
缺少或无效的零点标定会阻止启动；采集服务运行期间需先结束服务才能重新标定。

UMI 设备确认和采集监控页面的每路相机画面下方提供独立亮度调节，可拖动滑块、输入
数值或恢复硬件默认值。范围和步长读取相机实际能力，不支持的相机会显示提示。
调节直接作用于相机硬件，预览与保存图像使用相同的亮度；设备确认时已调好的亮度会
传入原 ROS 相机控制配置，进入采集后不会被重置为 0。

## 保存与模型

- 新回合使用 MP4 与传感器 MCAP；格式、原始时间戳与后台处理见[数据说明](../data/recording.md)。
- 历史数据质量提示不在操作页面显示，后台仍保留记录；当前采集错误和异常中断提示保留。
- PICO 安装点按同一份 CAD 基准恢复完整坐标精度，方向和左右镜像关系不变。来源见 [CAD 测量记录](../../umi_collection/vendor/galaxis/docs/galaxis_hand_cad_measurements.json)及[坐标说明](../../umi_collection/vendor/galaxis/docs/galaxis_hand_mirror_analysis_zh.md)。
