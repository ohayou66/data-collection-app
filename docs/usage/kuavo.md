# 乐聚 KUAVO 5-W 操作

[文档目录](../README.md) · [项目首页](../../README.md)

本页描述当前 App 的入口。机器人端网络服务版本决定可用参数和控制能力；源码合入不代表机器人服务已升级。早期接入中的“预留功能”和现场数据见[历史记录](../history/kuavo-and-camera-notes.md)，不作为当前状态判断。

## 连接与检查

1. 在遥操作配置中选择乐聚 KUAVO 5-W，填写任务，选择双臂或单臂模式。
2. 确认本电脑可以访问配置的机器人网络服务，PICO USB 已授权，Galaxis VR 有持续更新的输入。
3. 使用“检查设备”查看机器人、PICO 和 VR 状态。该流程会按服务能力进行主控及夹爪准备，不等同于开始遥操作；按界面的条件和结果继续。
4. 等待真实反馈就绪后再开始控制。结束后通过页面退出会话，保留原服务的会话所有权和退出流程。

网络使用本电脑的网卡与路由。连接凭据保存在本机运行目录，分发包不携带 token 或机器人私钥；旧版连接入口和服务能力以实际版本为准。

## 遥操作、采集与手动控制

- Grip 接管同侧手臂，Trigger 控制对应夹爪；单臂模式不接管另一侧。
- 回位、取消和采集按键受机器人服务及标注配置影响。选择子任务标注后采用统一 A/B/X/Y 定义，见[标注说明](overview.md#子任务标注)。
- 当前 App 包含相机预览、采集、手动关节步进与姿态保存入口；是否可执行由服务能力、反馈新鲜度和当前会话状态校验。
- 手动控制与遥操作互斥；改变模式、参数或姿态前，先结束不兼容的控制操作。界面选中的步长不表示机器人瞬间跳转。
- 本地采集 Episode 位于 `data/kuavo`；`episodes` 保存会话事件与诊断记录，二者用途不同。

## 模型与维护

运行时代码位于 `teleop_control/vendor/kuavo_runtime`。控制模型与显示资产分别位于 `teleop_control/assets/kuavo/` 和 `public/kuavo-model.json`，不要仅替换其中一份文件。显示模型不会替代机器人端控制和实机标定。

离线测试、模型显示与现场运动验收属于不同范围。安装与升级见[打包文档](../deployment/packaging.md)，最新本地功能合并验证见[记录](../../reports/remote-hotfix-merge-20261117.json)。
