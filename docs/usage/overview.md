## G2 入口

智元 G2 页面保留设备检查、速度/幅度、姿态预览、手动控制和三路相机预览。运行期间用 PICO 手柄 A 开始一段、B 完成一段；平台模式下完成数据进入后台上传队列。G2 需要对应架构的厂家 SDK 与机器人环境，不能仅凭界面可打开判断设备可用。

## 子任务标注

桌面和网页的“选择遥操作配置”页在任务名称后提供子任务标注配置。下拉列表可删除配置；“新建配置”可填写配置名称、添加自定义子任务卡片、直接重命名及上移/下移，确认后保存并选中，取消不保存。配置库保存在 `$XDG_CONFIG_HOME/xiaokai-lab-data-collection/subtask-configs.json`（默认 `~/.config`），两套界面共用本机服务；删除库中的配置不修改已保存的数据。

选择配置后，G2、天机和乐聚均使用 A 开始、B 保存、X 确认刚完成的一段并循环切换子任务、Y 重置下一项为第一项。乐聚此时 Y 不再执行回位，即使原采集开始键设为 X，本会话也使用 A；未选择标注配置时保留原按键行为。每轮采集从第一项及第 0 帧重新开始；Y 不清空已有标注，也不移动当前待标注区间的起点。没有新增保存帧的 X 不消耗一个子任务，停止前未按 X 确认的尾段保持未标注。

例如配置 `pick → move → place`，第 5 帧边界按 X 保存 `[0,5)` 为 pick，再过 6 帧按 X 保存 `[5,11)` 为 move。区间按最终保存的 bundles 帧和按键时间戳匹配；天机复用采集器的时钟偏移/漂移校正。`meta_info.json` 的 `subtask_annotation` 保存配置快照、原始按键事件、半开帧区间及平台时间区间。上传器将其同时写入 Episode extra，并通过平台现有 `/episodes/{id}/labels` 接口创建 `subtask` 标签，转换为平台包含末帧的时间范围；全部标签同步完成才记上传成功，重试按名称、时间范围和作者去重。云平台可视化显示对应帧类别及帧条；配置中还没有确认区间的名称显示为未分配帧的卡片。
