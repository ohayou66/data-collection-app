- 本机正式启动时启用独立后台保存服务，默认缓存位于 `teleop_control/runtime/tianji/save-queue`，完成数据仍进入原 `teleop_control/runtime/tianji/episodes`，沿用平台上传设置与子任务标注。完成入队即可继续下一轮，退出 App 不终止后台队列；保存失败保留缓存并按顺序重试，不完整数据不上传。界面显示待保存数量和服务错误。
- 控制器更新工具包含完整的重检、专用 USB 恢复、连续分段模块，以及相机服务退出后延迟 2 秒自动重启的配置；安装失败会恢复源码与服务配置。专用 USB 恢复仍要求双臂下使能、无采集和无其他 USB 设备。
- 0.39～0.44 秒是 11 月 9 日开发板上“结束采集到入队”的历史测试结果，不是本机保证值，也不是最终保存耗时。本次更新本机源码并做离线回归；重启 App 后使用新流程，现场相机与连续采集耗时仍需实测。

## 遥操作子任务标注（2026-10-29）

桌面和网页的“选择遥操作配置”页在任务名称后提供子任务标注配置。下拉列表可删除配置；“新建配置”可填写配置名称、添加自定义子任务卡片、直接重命名及上移/下移，确认后保存并选中，取消不保存。配置库保存在 `$XDG_CONFIG_HOME/xiaokai-lab-data-collection/subtask-configs.json`（默认 `~/.config`），两套界面共用本机服务；删除库中的配置不修改已保存的数据。

选择配置后，G2、天机和乐聚均使用 A 开始、B 保存、X 确认刚完成的一段并循环切换子任务、Y 重置下一项为第一项。乐聚此时 Y 不再执行回位，即使原采集开始键设为 X，本会话也使用 A；未选择标注配置时保留原按键行为。每轮采集从第一项及第 0 帧重新开始；Y 不清空已有标注，也不移动当前待标注区间的起点。没有新增保存帧的 X 不消耗一个子任务，停止前未按 X 确认的尾段保持未标注。

例如配置 `pick → move → place`，第 5 帧边界按 X 保存 `[0,5)` 为 pick，再过 6 帧按 X 保存 `[5,11)` 为 move。区间按最终保存的 bundles 帧和按键时间戳匹配；天机复用采集器的时钟偏移/漂移校正。`meta_info.json` 的 `subtask_annotation` 保存配置快照、原始按键事件、半开帧区间及平台时间区间。上传器将其同时写入 Episode extra，并通过平台现有 `/episodes/{id}/labels` 接口创建 `subtask` 标签，转换为平台包含末帧的时间范围；全部标签同步完成才记上传成功，重试按名称、时间范围和作者去重。云平台可视化显示对应帧类别及帧条；配置中还没有确认区间的名称显示为未分配帧的卡片。

## 最近更新（2026-10-20）

- 天机坐标映射参考 `test-teleop` 的相对位姿计算，使用天机厂家模型、硬件接口和完整关节限位；双臂采用一致的镜像关系及连续逆解，不对 J4 单独设置过零判定。
- 故障回零使用逐臂七关节直接归零流程，允许从已进入软件余量区、仍保持正间距的姿态向外恢复；硬件急停、持续伺服故障、硬限位和实际碰撞仍会阻止动作，不能保证任意故障下强行归零。
- 天机各路相机可选择硬件原生 30 fps 的 MJPEG 分辨率，并调节硬件亮度、恢复默认值。当前腕部相机提供 1024×768、1280×1024、1920×1080，亮度范围 −64～64；能力以实际设备返回为准。停止遥操与采集后方可修改。
- 采集固定本轮实际连接的相机清单，支持仅录制左右腕部；保存所选原始分辨率、硬件亮度读回值、坐标映射版本和实际 SDK 接受的关节指令。MJPEG 不再统一缩小成 640×480。
- 界面文本和错误提示支持选择复制；清理无用组件和已跟踪的 Python 缓存、运行日志及采集样本，保留本机文件而不继续纳入版本管理。
- 遥操页的机械臂模型与相机面板等宽、等高，模型视口随面板伸展；窄窗口自动切为同尺寸上下排列，保留视频下方的分辨率和亮度控件。
- 相机连接、错误与机器人检查分开处理；未录制时允许在遥操期间恢复相机预览，画面标题栏提供独立“重连视频”。读取分辨率和亮度直接使用当前流的已验证设置快照，不为读取设置停流或重复打开 USB。实际修改参数仍须先停止遥操与采集。相机异常会阻止或中止相应采集回合，但不会因视频重连失败而把成功的机器人检查改为失败。
- 相关回归覆盖双臂运动学、复位、相机预览与录制完整性，并检查安装包启动、安装后 Qt 控件及网页端类型。控制器双路相机实测约 29.8 fps；未自动执行机械臂实机动作或真实平台上传验收。

- 左右夹爪按实际安装各绕纵轴旋转 180°，安装 yaw 为左 −45°、右 +135°；URDF、工具坐标和显示模型同步，工具点位置和指尖纵轴保持一致。
- 修正复位导致预览锁定：只识别已核对的伺服复位日志；新版客户端与服务协商后，关节采样延迟或反馈错误单独发送健康状态，视频继续显示。单纯的关节采样延迟仅记录质量信息，不再阻止或中断采集；真实反馈错误仍阻止采集，恢复后须收到真实关节反馈。USB、实时任务及未知日志检查继续生效。

**已知相机问题：** 反复切换分辨率或热插拔时，仍复现过连续流中的无效 MJPEG 帧，以及右相机标准 USB 请求超时。正常录制保留严格校验，失败回合不会标为完整或自动上传。相机设置功能和一次完整后端切换流程已通过实测，但上述间歇故障尚未根治；一次恢复出图或断电重启成功不能视为问题已解决。
